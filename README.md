# ETC利用明細 車番別 金額振り分け

ETC利用照会サービスの「ご利用明細書」PDFを解析し、車両番号ごとに通行料金を
集計して `高速料金` シートのC列に振り分けます。

## 使い方

```
pip install openpyxl pdfplumber
python scripts/etc_allocate_by_vehicle.py
```

スクリプト先頭の `PDF` / `XLSX` / `OUT` のパスを対象ファイルに合わせて変更してください。

## 出力シート

| シート | 内容 |
|---|---|
| `高速料金` | 車番（担当者）ごとの集計。C列＝金額、D列＝振替の備考 |
| `車番別明細` | 車番ごとの利用明細1件1行。日付・時刻・入口/出口ＩＣ・通行料金・割引種別、車番ごとの小計付き |

件数は出力しません。

`車番別明細` の備考欄には、単独課金（本線料金所などの均一区間）と、
乗り替わりで別の車番に乗った明細（`実車番○○ に乗車`）が表示されます。

## 明細PDFのレコード構造

1レコードは3行で構成されます。

```
利用年月日(自) 利用年月日(至) (割引前料金) 車種   備考
時分(自)       時分(至)       (ETC割引額)  車両番号
利用IC(自)     利用IC(至)     通行料金     ETCカード番号
```

- 割引が無いレコードでは `(割引前料金)` `(ETC割引額)` が出力されません。
- 本線料金所（日光本線料金所・大沢本線料金所など）の単独課金レコードは
  日付・時刻が1つしか出力されないため、時刻行の判定は「1つまたは2つ」を許容します。
- 集計対象は割引適用後の **通行料金**（3行目）です。

## 乗り替わりの付け替え

代車・乗り替わりでドライバーが入れ替わった日は、スクリプト冒頭の `OVERRIDES` に
`(実際に走った車番, 利用日)` → `料金を負担する車番` を登録すると、その日の明細だけが
付け替えられ、E列に備考が入ります。

```python
OVERRIDES = {
    (46, '26/08/20'): 9283,   # 8/20・8/21は車番46に伊垣さん(9283)が乗車
    (46, '26/08/21'): 9283,
}
```

判定は利用開始日（利用年月日(自)）基準です。

## 検証

集計値の合計が明細書1枚目の「通行料金合計」と一致することを確認しています。

- 通行料金合計: ￥4,937,200（PDF記載の合計と一致）

付け替えは車番間の移動のみで総額は変わらないため、付け替え後も合計は一致します。

# ツーマン 出勤表作成

頭（運転の主担当）と助手の2人1組で運行する出勤表を、希望休・連勤上限・平均出勤日数を
守りながら自動で作成します。手書きの出勤表と同じ様式（縦＝日付、横＝氏名、
セル＝号車 or 休）で出力します。

```
pip install openpyxl
python scripts/shift_schedule.py
```

## 号車の書き方

頭は号車が固定です（`HEADS` の並び順に ①②③④⑤）。相方はその日に乗る号車を書くので、
**同じ号車が並んでいる2人がその日のツーマン**になります。

頭の人数が組数より多い日は、余った頭が助手席に回ります（輪番）。その頭の号車は
その日は運休になり、`車台数` の列に実際に動かす台数が入ります。

## 設定（スクリプト冒頭）

| 項目 | 内容 |
|---|---|
| `YEAR` / `MONTH` | 対象年月 |
| `HEADS` / `ASSISTANTS` | 頭・助手の氏名リスト。頭の並び順がそのまま号車番号になる |
| `EXTRA_COLUMNS` | 出勤表に列だけ用意して、ローテーションには入れない人 |
| `TARGET_AVG_WORK_DAYS` | 1人あたりの平均出勤日数。平日の組数を自動で調整して合わせる |
| `CREWS_WEEKEND` | 土日に出す組数（土日を多めに出す設定） |
| `CREWS_WEEKDAY` | `TARGET_AVG_WORK_DAYS` を `None` にしたときの平日の組数 |
| `MAX_CREWS` | 車の台数 |
| `CREWS_OVERRIDE` | 日にち→組数。祝日や繁忙日だけ個別に増減する |
| `REQUESTED_OFF` | 氏名→希望休の日にちリスト |
| `MAX_CONSECUTIVE` | 連続出勤の上限日数 |
| `CARRY_IN_STREAK` | 前月末時点の連勤日数。月をまたぐ連勤を防ぐ |
| `SEED` | 乱数種。変えると同じ条件で別パターンが出る |

`TARGET_AVG_WORK_DAYS` を決めると、`人数 × 平均出勤日数 ÷ 2` が必要な組日数になり、
土日分を引いた残りを平日に割り振ります。端数の「1組多い日」は月内に均等にばらけさせます。

## 守る条件

- 希望休は必ず休みにする。
- 連続出勤は `MAX_CONSECUTIVE` 日まで（前月からの連勤も加算）。
- 1組は必ず頭を1名含む。
- 出勤日数・土日の出勤回数をメンバー間で平準化する（差は最大1日）。
- 同じ2人の組み合わせが偏らないよう、毎日ペアを組み替える。
- 頭が助手席に回る回数も頭の間で平準化する。

希望休が重なって予定の組数を出せない日は、その日の組数を自動で下げ、`備考` シートと
実行時のログに「10/3(土) 希望休のため 4組 → 3組」のように記録します。

## 出力シート

| シート | 内容 |
|---|---|
| `出勤表` | 手書き様式そのまま。縦＝日付＋曜日、横＝氏名、左に車台数、下に合計・残業。セルは号車（①②③④⑤）か `休`。希望休の `休` は黄色 |
| `組み合わせ` | 日ごとの号車別の相方。運休の号車は `運休` |
| `備考` | 設定内容・希望休の一覧・1人ずつの出勤日数と最大連勤・組数を下げた日 |
