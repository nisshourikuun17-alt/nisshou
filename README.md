# 支払一覧 年別整理ツール

4か月ごと（3〜6月 / 7〜10月 / 11〜翌2月）に分かれた支払一覧の Excel ブックを、
**暦年ごと（1月〜12月）に1シート**へ再編するスクリプト群です。

## 元ファイルの構造

月は「行」ではなく **3列ずつの列ブロック** として横に並んでいます。

| 列 | 内容 |
|---|---|
| A / D / G / J | 支払先 |
| B / E / H / K | 金額 |
| C / F / I / L | 日 |

1シートに4か月ぶんの列ブロックが並び、M列以降には作業用データが不定形に入っています。

## 出力

- 1年 = 1シート、1月〜12月を左から横に並べた36列構成
  （1月=A〜C、2月=D〜F、… 12月=AH〜AJ）
- 1行目を月見出し専用行とし、データは元の行番号から1行ぶん下へ移動
  （数式の行参照・列参照も同じだけ自動変換）
- AL列より右は「補助領域」。元シートのM列以降と、重複していた月ブロックを
  出典タブ名付きで退避
- 先頭に「◎このブックについて」シートを生成し、変換内容と要確認事項を記載

## 使い方

```bash
pip install openpyxl
cd scripts
# source.xlsx を同じディレクトリに置く
python3 build.py      # payments_by_year.xlsx を生成
python3 finalize.py   # 説明シートを追加し、シート順を整える
python3 verify.py     # 元ファイルと1セルずつ照合
```

## スクリプト

| ファイル | 役割 |
|---|---|
| `map.py` | タブ名・和暦見出しの解析（全角/半角、令和・平成、表記ゆれを吸収） |
| `build.py` | 月ブロックの特定 → 年シートへの再配置、数式の座標変換、書式の複製 |
| `finalize.py` | 説明シートの生成、シート順の整理 |
| `verify.py` | 元ファイルとの全セル照合、数値合計の一致確認 |

## 設計上の注意

- **書式を守るため、表計算ソフトでの再保存（再計算）は行いません。**
  LibreOffice を通すと日本語フォント (MS PGothic) が別フォントに置換されるためです。
  数式にキャッシュ値は入りませんが、Excel / Google スプレッドシートで開けば
  自動的に再計算されます。
- 数式は同一ブロック内参照が大半のため、列オフセットと行シフトのみで変換できます。
  年をまたいで別シートに分かれる参照は変換せず、ログに記録します。
- 実データ（`*.xlsx`）は `.gitignore` で除外しています。
